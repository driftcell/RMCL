# 产品范围

状态：已接受

日期：2026-10-25

## 产品定位

RMCL 是使用 Rust 独立实现的 Minecraft 启动器，以约定的 HMCL 基线作为长期功能对齐目标，而不是 HMCL JavaFX 界面的逐像素复刻或 Java 源码的逐行翻译。

界面使用 GPUI Kit，并允许在不丢失功能的前提下重新组织交互，使常用流程更清晰、符合人体工程学。

## 初始平台

首批平台限定为：

- Windows
- Linux
- macOS

“对齐 HMCL 功能”不自动等于继承 HMCL 的全部操作系统与 CPU 架构支持。其他平台和架构不在首批承诺范围内。

## 数据与配置

- 支持发现、读取和复用已有 `.minecraft` 目录及标准游戏数据布局。
- RMCL 使用自己的启动器配置、状态与迁移机制。
- 不要求用户继续依赖 HMCL 配置，也不原地改写 HMCL 配置。
- HMCL 配置导入是可选的后续附加功能，不属于首个里程碑的前置条件。

## Java 边界

RMCL 自身编译为原生桌面二进制，不要求用户为了运行启动器而预装 JVM。

Minecraft Java Edition 及部分游戏组件安装器仍需 Java。RMCL 必须保留 Java 检测、选择、自动下载和实例级覆盖能力，不能把“原生启动器”理解为“不再需要 Java 运行游戏”。

## 长期对齐方式

以 [HMCL 固定基线](../compatibility/HMCL_BASELINE.md) 建立功能台账，逐项记录支持平台、实现位置、测试和差异。功能清单未完成、验证未通过前，不宣称已经完整对齐 HMCL。
